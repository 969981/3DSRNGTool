# Pokémon 3DS RNG Tool

This context describes generated Pokémon results and the filters used to find them.

## Language

**Shiny result**:
A generated Pokémon whose appearance is shiny.

**Star shiny**:
A shiny result with the star-type shiny effect rather than the square-type effect.
_Avoid_: Regular shiny when distinguishing it from square shiny

**Square shiny**:
A shiny result with the square-type shiny effect.

**Shiny filter mode**:
The requested shiny category for result searches: `Any`, `No Shiny`, `Star Only`, `Square Only`, or `Star / Square`.
The default mode is `Any`.
